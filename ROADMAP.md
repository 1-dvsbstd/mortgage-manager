# Mortgage Manager Roadmap

## V0.1 — Personal prototype
- Remaining term as the main figure
- Current balance, rate and monthly payment
- £0 / £50 / £100 / £250 / £500 overpayment scenarios
- Estimated interest saved
- Estimated term reduction
- Mortgage balance graph
- Manual home value, equity and LTV

## V0.2 — Better mortgage modelling
- Fixed-rate end date
- Mortgage-free calendar date
- Remortgage/update flow
- Clear actual vs projected values
- Better mobile charts
- Custom overpayment input
- Lump-sum overpayments

## V0.3 — Home value layer
- Property profile
- Recent comparable sales
- Estimated value range
- Confidence indicator
- Equity and LTV history

## V0.4 — Nice-to-know tools
- Rough borrowing power
- Indicative next-home budget
- Optional route to relevant property searches

## V0.5 — PWA and sharing
- Installable PWA
- Local persistence
- Cloud sync option
- Shared household/home for partners
- Reminder when fixed deal is approaching expiry

## V1.0 — Public-ready
- First-run onboarding
- Robust validation and calculation tests
- Privacy and data handling documentation
- Clear planning-tool disclaimers
- Branding and mobile polish
- Export/import
- Analytics with privacy in mind
- Pricing and distribution plan

## Offline / Etsy edition
Built from the same calculation logic, but designed to work without accounts or a backend.

Possible features:
- Mortgage planning
- Overpayment scenarios
- Balance graph
- Manual home value / LTV
- Import/export of local data
- Lifetime-use positioning
