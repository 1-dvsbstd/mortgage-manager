# Mortgage Manager

A visual UK-focused mortgage planning app.

The goal is not to replace a lender statement. It is to make a mortgage easier to understand by showing:

- estimated time remaining
- current mortgage balance
- the effect of regular overpayments
- estimated interest saved
- term reduction
- mortgage balance trajectory
- home value, equity and LTV

## Current version

V0.1 is a simple browser-based prototype using vanilla HTML, CSS and JavaScript.

Open `index.html` in a browser to run it locally.

## Product direction

The project is being developed in two directions from a shared calculation core:

1. **Web/PWA** — installable on phone, with future persistence, partner sharing, reminders and online property-data features.
2. **Offline edition** — a self-contained version suitable for one-off distribution, such as an Etsy download.

## Principle

The opening experience should answer three questions quickly:

1. How long do I have left?
2. What would a small overpayment change?
3. How is my mortgage balance falling over time?

The app is an illustrative planning tool, not financial advice or a lender affordability decision.
